# Almaz Tour — сайт туристического агентства

Современный сайт агентства Almaz Tour (Астана): Next.js 16 (App Router) + TypeScript + Tailwind CSS 4. Полный редизайн almaztour.kz с сохранением всех реальных данных: контактов, отзывов, текстов направлений и интеграции с Tourvisor.

## Запуск

```bash
npm install
npm run dev        # разработка на http://localhost:3000
npm run build      # продакшен-сборка
npm start          # запуск собранного сайта
```

Требуется Node.js 20.9+; текущие проверки выполнены на Node.js 24.

Сайт открывается на `/ru` и `/kk`. Старые адреса перенаправляются на русскую
версию. В `src/app/[locale]/layout.tsx` находится единственная оболочка сайта;
`global-not-found.tsx` обслуживает неизвестные адреса через документированную
экспериментальную настройку Next.js `globalNotFound`.

Светлая, тёмная и системная темы сохраняются локально. Плавная прокрутка
реализована Lenis, параллакс фотографии — GSAP ScrollTrigger. На сенсорных
устройствах прокрутка нативная; параллакс включён только на настольных экранах
с точным указателем и отключается при `prefers-reduced-motion`. Секции остаются
видимыми без JavaScript.

Проверки: `node --test tests/*.test.cjs`, `npx tsc --noEmit`, `npm run lint`,
`npm run build`. Браузерный сценарий `scripts/verify-browser.cjs` требует
Playwright через `NODE_PATH` и Chrome (путь можно задать через `CHROME_PATH`),
а также production-сервер на порту 3100. Он подменяет внешний Tourvisor и
отправки форм, не обращаясь к реальным получателям.

## Tourvisor

Поиск туров и горящие туры подтягиваются встраиваемыми модулями Tourvisor.
ID модулей задаются в `.env.local` (пример — в `.env.example`):

```
NEXT_PUBLIC_TV_SEARCH_ID=...     # модуль «Поиск туров»
NEXT_PUBLIC_TV_HOT_HOME_ID=...   # «Горящие туры» на главной
NEXT_PUBLIC_TV_HOT_PAGE_ID=...   # «Горящие туры» на /hot-tours
```

Где взять свои ID:

1. Зарегистрируйтесь или войдите в кабинет партнёра: https://pro.tourvisor.ru
2. Раздел «Модули для сайта» → создайте модуль нужного типа
   («Поиск туров», «Горящие туры»).
3. В коде вставки модуля будет строка вида `tv-moduleid-9955693` —
   число из неё и есть ID.
4. Там же в кабинете настраиваются город вылета по умолчанию (Астана),
   цвета и поля модуля — подгоните их под палитру сайта:
   тёмно-синий `#000942`, золотой `#FFCC00`, лазурный `#5DA8D3`.

Важно: модули привязываются к домену сайта в кабинете Tourvisor, поэтому
на localhost виджет может не отрисоваться. В этом случае компонент
`TourvisorModule` показывает запасной блок с кнопкой WhatsApp — это
возможное поведение. Готовность виджета на целевом домене требует отдельной
проверки кабинета, доступа и настроек поставщика; сама смена домена её не гарантирует.

Скрипт вставляется один раз на документ, ожидание ограничено 15 секундами
от начала попытки. При отказе появляется компактный блок на текущем языке:
заявка, WhatsApp и ручная перезагрузка страницы. Документированный способ
перезапуска этого модуля при SPA-навигации пока не установлен: при необходимости
перезагрузка загружает официальный embed заново. Живая выдача в локальных
проверках не подтверждалась.

Ещё нюанс: виджет сам определяет город вылета по IP посетителя. Если при
разработке вы видите «из Перми» и цены в рублях — это гео-детект, а не
ошибка. Город вылета по умолчанию (Астана) и валюту жёстко фиксируют в
настройках модуля в кабинете pro.tourvisor.ru.

## Формы

Формы «Подобрать тур», «Оставить отзыв» и подписка валидируются на клиенте
и отправляются в API-роуты (`src/app/api/*`). Данные уходят в Telegram через
общий хелпер `src/lib/telegram.ts`; тела заявок не пишутся в диагностические
логи. Базы заявок и автоматической рассылки нет. Отзывы передаются менеджеру,
но не публикуются автоматически.

### Подключение Telegram

1. **Создайте бота.** Напишите [@BotFather](https://t.me/BotFather) в
   Telegram → команда `/newbot` → задайте имя и username бота. BotFather
   выдаст токен вида `1234567890:AA...` — это `TELEGRAM_BOT_TOKEN`.
2. **Узнайте chat_id.** Напишите своему боту любое сообщение (бот не может
   написать первым), затем откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе будет
   `"chat":{"id":123456789,...}`, это число и есть `TELEGRAM_CHAT_ID`.
   Чтобы заявки приходили в группу, добавьте бота в группу и возьмите её id
   оттуда же (у групп он отрицательный, вида `-100...`).
3. **Задайте переменные.** Локально — в `.env.local`:

   ```
   TELEGRAM_BOT_TOKEN=1234567890:AA...
   TELEGRAM_CHAT_ID=123456789
   TELEGRAM_CHAT_IDS=987654321,555555555
   ```

   На Vercel — Settings → Environment Variables, те же имена
   (для Production и Preview), затем передеплойте проект.

### Уведомления маме и менеджерам

`TELEGRAM_CHAT_ID` сохраняет текущего получателя. В `TELEGRAM_CHAT_IDS`
перечислите дополнительные chat_id через запятую. Можно использовать только
`TELEGRAM_CHAT_IDS`: повторяющиеся ID автоматически исключаются. Все три
формы отправляют одинаковое уведомление всем настроенным получателям.

Каждый получатель должен открыть вашего бота и нажать **Start** или отправить
`/start`. Для общей группы добавьте туда маму, менеджеров и бота с правом
отправлять сообщения; укажите ID группы вместо личных ID. После сообщений
получателей возьмите `message.chat.id` через `getUpdates` по инструкции выше.
Если бот уже использует webhook, `getUpdates` недоступен — ID берётся из
входящего обновления существующего обработчика; не отключайте webhook ради ID.

При частичной доставке сайт подтверждает приём заявки, а серверный лог
показывает число успешных отправок и ошибки по чатам. Неудачные отправки
автоматически не повторяются. Если не получил никто, форма получает ошибку
502. После настройки проверьте тестовую заявку у каждого получателя.

Это серверные секреты: префикс `NEXT_PUBLIC_` не нужен, в клиентский бандл
они не попадают. Если переменные не заданы, форма получает 503 и предлагает
связаться напрямую; успешная отправка не имитируется. Если Telegram недоступен, роут
отвечает 502, и форма показывает посетителю запасное сообщение с просьбой
позвонить.

## Деплой

Проще всего — Vercel:

```bash
npx vercel
```

Не забудьте добавить переменные из `.env.local` в настройки проекта
(Settings → Environment Variables). Подойдёт и любой сервер с Node.js:
`npm run build && npm start` за реверс-прокси.
